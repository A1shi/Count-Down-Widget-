# Count Down & Widget

A Flutter-based countdown application that helps users track important events, deadlines, and special dates. The app also provides home screen widgets for quickly viewing countdown information without opening the application.
## 📱 Download the App

The app is available on Google Play Store:

👉 [Download Count Down & Widget on Google Play](https://play.google.com/store/apps/details?id=com.aashigupta_countdown&pcampaignid=web_share)
## Features

- Create countdowns for important events
- Track deadlines and goal dates
- View remaining days and time
- Edit existing countdowns
- Delete countdowns
- Home screen countdown widget
- Deadline widget
- Local data storage using SharedPreferences
- Local notifications and reminders
- Persistent countdown data

## Screens

The application allows users to manage countdowns and track important dates from a simple interface.

Getting Started
Prerequisites
Flutter SDK
Dart SDK
Android Studio or VS Code
Installation

Clone the repository:

git clone https://github.com/A1shi/Count-Down-Widget-.git

Navigate to the project folder:

cd Count-Down-Widget-

Install dependencies:

flutter pub get

Run the application:

flutter run
Android Widgets

The project includes native Android widgets implemented using Kotlin:

Countdown Widget
Deadline Widget

These widgets allow users to view important countdown information directly from their Android home screen.
